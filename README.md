# 🖼️ Screenshot of a Screenshot — Graphics Experiment

A small graphics experiment exploring how repeatedly taking screenshots of an image affects its resolution and file size.

## 🖼️ Original Image

![Original Image](images/original image.jpg)

## 🔬 Experiment

I started with a JPG image and repeatedly took screenshots of the previous screenshot using an Android device.

Interestingly, after the first screenshot, the resolution remained the same, but the file size kept decreasing.

## 📊 Results

| Generation | Resolution | File Size |
|---|---|---|
| Original | 1875 × 2600 | 1.73 MB |
| Screenshot 01 | 720 × 1640 | 230 KB |
| Screenshot 02 | 720 × 1640 | 229 KB |
| Screenshot 03 | 720 × 1640 | 228 KB |

## 👀 Observations

- The original image was significantly reduced in resolution.
- Subsequent screenshots maintained the same resolution.
- File size decreased by approximately 1 KB with each screenshot.
- The image remained visually recognizable.

## 💭 What I Found Interesting

Even though the resolution stayed identical, the file size continued to decrease.

Repeated JPEG encoding could explain this behavior, as each encoding may change the compressed image data.
